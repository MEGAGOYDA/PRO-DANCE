# PRO DANCE

Адаптивный сайт танцевальной команды на чистых HTML, CSS и JavaScript. Сборка и установка зависимостей не нужны. Шрифты, фотографии и значок хранятся локально, внешние сервисы не используются.

## Как открыть

Откройте `index.html` двойным щелчком в любом современном браузере. Интернет для работы страницы не требуется.

Для локального просмотра через сервер перейдите в папку `ChatGPT` и выполните `python -m http.server 8000`. Затем откройте http://localhost:8000. Остановка сервера: Ctrl+C. Этот вариант необязателен; требуется установленный Python.

## Файлы

- `index.html` — разметка, тексты, подписи полей, галерея и FAQ.
- `style.css` — оформление, мобильные версии и уменьшение анимации.
- `script.js` — мобильное меню, переход к форме с выбранной группой, проверка полей.
- `assets/` — пять предоставленных пользователем фотографий, значок и локальные шрифты.

## Что работает

Меню с якорями и плавной прокруткой; мобильное меню с Escape и удержанием клавиатурного фокуса; кнопки записи с выбором группы; раскрывающиеся вопросы; проверка имени, телефона, возраста и соответствия группы возрасту. Возраст 6–9 автоматически выбирает PRO KIDS, 10–16 — PRO JUNIOR. Группу можно изменить, но несоответствие возрасту будет показано перед проверкой заявки.

Форма **демонстрационная**: отправка отсутствует. Сообщение об этом видно до заполнения и после проверки. Данные не передаются, не записываются в localStorage, cookie или другие хранилища. Без JavaScript кнопка формы отключена. При подключении сервера замените обработчик и обновите сообщения, политику обработки данных и необходимые согласия.

## Доступность и оформление

Русский язык страницы, семантические разделы, видимые подписи полей и состояния фокуса, ссылка перехода к содержимому, сообщения ошибок с `aria-describedby`, статус формы с `aria-live`, управление FAQ с клавиатуры. Настройка `prefers-reduced-motion` отключает плавную прокрутку и переходы. Фотографии имеют размеры и альтернативные описания, второе фото загружается отложенно.

Шрифты Oswald и Manrope распространяются по SIL Open Font License; лицензии сохранены в `assets/fonts/`. Для заголовков используется Oswald, для основного текста — Manrope; предусмотрены системные замены.

## Проверка

Результаты проверки страницы и интерфейса записаны в `CHECKS.md`. При изменении формы или адаптивных стилей повторите проверку на узком экране, переходы меню, обе кнопки групп, некорректный и корректный ввод, отключённый JavaScript и уменьшение анимации.
